# HPY69

HPY69 is a 69-key, ANSI-layout integrated keyboard.

### Features

- 69-key ANSI integrated layout
- Supports both BLE Micro Pro (legacy) and BMP Boost (latest)
- Vial enabled by default
- OLED shows status such as BLE connection target

### Notes

- For BLE Micro Pro (BMP) details, see the repository and official documentation by sekigon-gonnoc:
  [BLE-Micro-Pro repository](https://github.com/sekigon-gonnoc/BLE-Micro-Pro.git)
  [Official documentation](https://sekigon-gonnoc.github.io/BLE-Micro-Pro/#/)
- This keyboard definition extends `keyboards/ble_micro_pro`.
- Vial configuration is required because this keyboard uses duplexMatrix.
- The default keymap includes BLE control layers, OLED image assets, and custom status handling for USB/BLE output state.

---
### File Structure

- `keyboards/duml3455/hpy69/`
  Keyboard definition, platform settings, and linker script
- `keyboards/duml3455/hpy69/keymaps/default/`
  Default Vial keymap, OLED images, and BLE/OLED state handling
- `keyboards/duml3455/hpy69/bmpconfig/`
  Stores default `duml3455_HPY69_single_config.json` and `duml3455_HPY69_single_config.bin`

---
### Build

Build the default keymap:

```sh
make duml3455/hpy69:default:uf2
```

### Flash

Connect BMP in DFU mode, then flash the compiled `duml3455_hpy69_default.uf2`.

After flashing `.uf2`, write `keyboards/duml3455/hpy69/bmpconfig/config.bin`.
See: [Write a configuration file to BLE Micro Pro](https://sekigon-gonnoc.github.io/BLE-Micro-Pro/#/about_config_files?id=ble-micro-pro%e3%81%ab%e8%a8%ad%e5%ae%9a%e3%83%95%e3%82%a1%e3%82%a4%e3%83%ab%e3%82%92%e6%9b%b8%e3%81%8d%e8%be%bc%e3%82%80)

### Default Keymap

The default keymap has these layers:

- Base typing layer
- Function layer
- BLE control layer
- BLE bond delete layer

You can edit key assignments using either [VIA custom UI for Vial](https://sekigon-gonnoc.github.io/via-custom-ui-for-vial/) or [Vial Web](https://vial.rocks/).
VIA and Remap are not supported.

The default keymap already includes BLE custom keycodes, so you can use them right after flashing without remapping in Vial.

It also has a behavior where pressing Left Shift + Space sends `KC_LNG2` first.
You can enable/disable this with the flag below in `keyboards/duml3455/hpy69/keymaps/default/config.h`:

- `#define HPY69_ENABLE_SHIFT_SPACE_LNG2 1` : enabled (default)
- `#define HPY69_ENABLE_SHIFT_SPACE_LNG2 0` : disabled

---
### Status Display

The default OLED displays:

- USB connection state
- BLE idle state
- BLE advertising without whitelist (for pairing)
- BLE advertising to a whitelisted device
- BLE connected state to a whitelisted device

By default, all OLED screens are rendered from bitmap image data.
For editing image data, see [OLED Bitmap Data Generation](#oled-bitmap-data-generation).

OLED timeout and brightness are configured in:

`keyboards/duml3455/hpy69/keymaps/default/config.h`

---
### OLED Bitmap Data Generation

By default, OLED screens are rendered from binary bitmap data.
If you want to replace the bitmap data, [image2cpp](https://javl.github.io/image2cpp/) is convenient.

1. Set a 128x32 pixel image in `Select image`.
2. If you need inverted colors, set `Background color: Black`.
3. Check `Preview`.
4. Set `Code output format: Plain bytes`.
5. Set `Draw mode: Horizontal - 1 bit per pixel`.
6. Click `Generate code`.
7. Paste the generated byte data into [images.c](keymaps/default/images.c) and update definitions as needed.

---
### Future Extension

The keymap is already modularized, so BLE state handling and OLED behavior can be extended with relatively small changes.

- `bmp_status.c/.h`
- `oled_status.c/.h`

## HPY69 日本語説明

HPY69 は、69 キー ANSI 配列一体型キーボードです。

### 特徴

- 69キー、ANSI配列、一体型
- BLE Micro Pro(旧版) と BMP Boost(最新版) 両対応
- デフォルトでVialに対応
- OLEDには、BLE接続先などのステータスを表示

### 補足

- BLE Micro Pro (以下BMP)の詳細は、BMP開発者である sekigon-gonnoc さんが公開している [リポジトリ](https://github.com/sekigon-gonnoc/BLE-Micro-Pro.git) 並びに、 [公式ドキュメント](https://sekigon-gonnoc.github.io/BLE-Micro-Pro/#/) を参照してください。
- キーボード定義等は `keyboards/ble_micro_pro` を拡張して作成しています。
- duplexMatrix を使用しているので、Vial設定は必須です。
- デフォルトキーマップには BLE 制御用レイヤー、OLED 描画画像アセット、USB/BLE 出力状態を扱う独自ステータス処理が含まれています。

### フラッシュ
DFUモードでBMPを接続し、コンパイルした `duml3455_hpy69_default.uf2` をフラッシュしてください。

`.uf2` のフラッシュ後には、 `keyboards/duml3455/hpy69/bmpconfig/config.bin` を書き込んでください。[BLE Micro Pro に設定ファイルを書き込む](https://sekigon-gonnoc.github.io/BLE-Micro-Pro/#/about_config_files?id=ble-micro-pro%e3%81%ab%e8%a8%ad%e5%ae%9a%e3%83%95%e3%82%a1%e3%82%a4%e3%83%ab%e3%82%92%e6%9b%b8%e3%81%8d%e8%be%bc%e3%82%80)

### デフォルトキーマップ

デフォルトキーマップは次のレイヤーを設定しています。

- 通常入力用のベースレイヤー
- ファンクションレイヤー
- BLE 制御レイヤー
- BLE ボンド削除レイヤー

sekigon-gonnoc さんが公開している [VIA custom UI for Vial](https://sekigon-gonnoc.github.io/via-custom-ui-for-vial/) あるいは [Vial Web](https://vial.rocks/) で変更できます。
VIA、Remapには対応していません。

なお、デフォルトキーマップにはすでに BLE 関連の独自キーコードを組み込んでいるため、フラッシュ直後から Vial で再割り当てしなくても使用できます。

また、左 Shift を押しながら Space を押したときに `KC_LNG2` を先に送る挙動を持っています。
この挙動は `keyboards/duml3455/hpy69/keymaps/default/config.h` の下記フラグで ON/OFF できます。

- `#define HPY69_ENABLE_SHIFT_SPACE_LNG2 1` : 有効 (デフォルト)
- `#define HPY69_ENABLE_SHIFT_SPACE_LNG2 0` : 無効

---
### ステータス表示

デフォルトキーマップの OLED では次を表示します。

- USB 接続状態
- BLE アイドル状態
- BLE ホワイトリストなしアドバタイズ状態(BLEペアリング用)
- BLE ホワイトリスト登録済み機器へのアドバタイズ状態
- BLE ホワイトリスト登録済み機器への接続状態

デフォルトでは、すべて画像描画として表示しています。
描画データを編集する場合は [こちら](#oled描画バイナリ作成)

OLED のタイムアウトと輝度は下記で設定しています。

`keyboards/duml3455/hpy69/keymaps/default/config.h`

---
### OLED描画バイナリ作成
デフォルトでのOLEDは、すべてバイナリデータを描画する設定となっています。
描画するバイナリデータを変更したい場合は、 [image2cpp](https://javl.github.io/image2cpp/) が便利です。

1. Select image で 128x32 pixel 画像データを指定
2. 指定した画像データの色を反転する場合は、Background color: Black を指定
3. Preview を確認
4. Code output format: Plain bytes を指定
5. Draw mode: Horizontal - 1 bit per pixel を指定
6. Generate code をクリック
7. 生成されたテキストデータを、[images.c](keymaps/default/images.c) に貼付し、必要に応じて定義する
